# Changelog

## [0.6.0] - 2026-10-10

### Added
- mobile-first app shell
- fixed phone-size desktop UI
- full-screen mobile UI
- 8-language language selector
- spread library
- position meanings
- Daily Card
- Past / Present / Future
- You / Them / Relationship
- Five-Card Guidance
- Romance Opportunities / 桃花牌阵
- Career Five-Card Spread
- optional question field
- position × card interpretation
- local reading history
- 78-card library
- PWA icons

### Changed
- core logic changed from “choose card count” to “choose a spread”
- every revealed card is now tied to a position meaning
- desktop is no longer a wide web layout

### Note
Spread definitions are Lunar Arcana templates and may differ from other tarot readers.
